# Proposal

## Why

AI 답변 아래의 "참고 리뷰" 카드는 별점, 작성자, 제목, 내용만 보여준다. 사용자가 근거를 한눈에 판단하려면 누가 언제 쓴 리뷰인지, 검색 결과에서 얼마나 관련 있는지가 보여야 하고, 긴 리뷰는 카드가 지나치게 길어지지 않으면서도 원문을 끝까지 읽을 수 있어야 한다. 응답은 이미 `date`와 `score`를 내려주고 있지만 화면은 쓰지 않는다.

## What Changes

- 별점을 노란색 별 아이콘(1~5)으로 시각화한다(현재 구현을 요구사항으로 명시하고 접근 가능한 이름을 유지).
- 작성자와 작성일을 아이콘이 붙은 메타 태그로 표시한다. 값이 없으면 해당 태그를 숨긴다.
- 리뷰 내용이 길면 2줄에서 말줄임 처리하고, 내용이나 "더보기" 버튼을 누르면 전체를 펼치고 다시 접을 수 있게 한다. 짧은 내용에는 토글을 보이지 않는다.
- 검색 점수를 백분율 배지(예: "89% 일치")로 표시한다. 배지에는 이 값이 키워드 관련도와 도움이 됨 수를 조합한 표시용 점수이며 의미 유사도가 아니라는 설명을 툴팁과 접근성 이름으로 함께 제공한다.

범위 밖: API 응답 변경(`date`, `score`는 이미 제공됨), 점수 산식 변경, 카드 목록 정렬·필터, 카드 내용의 복사·공유 기능.

## Impact

- 수정 코드: `src/components/SourceCard.tsx`, 관련 테스트.
- 신규 코드: `src/components/ExpandableText.tsx`(말줄임·펼치기), `src/lib/format.ts`(날짜·일치율 표기 변환), 각 테스트.
- API, 타입, 서버 코드 변경 없음(`SourceReview`에 `date`와 `score`가 이미 있음).
- 새 의존성 없음. 아이콘은 기존 `lucide-react`를 쓴다.
- 가정: 일치율은 `score`(0.65~0.98)를 100배해 반올림한 값이다. 요청서의 "89% 일치" 표기를 따르되, 점수는 코사인 유사도가 아니라 정규화한 표시용 값이므로 툴팁으로 의미를 밝힌다. 키워드가 매칭되지 않아 인기 리뷰가 기본 반환된 경우도 응답만으로는 구분할 수 없어 같은 방식으로 표시된다.
- 가정: 작성일은 `YYYY-MM-DD` 형식이면 `YYYY.MM.DD`로 보여주고, 다른 형식이면 원문을 그대로 보여준다.
- 가정: 키가 없을 때는 서버가 `sources`를 비워 보내므로 이 카드들은 `ANTHROPIC_API_KEY`가 설정된 경우에만 화면에 나타난다.
