# Spec Delta

## MODIFIED Requirements

### Requirement: 참고 리뷰 아코디언
시스템은 AI 답변 하단에 근거 리뷰가 있으면 "참고 리뷰 N건" 배지와 아코디언을 표시해야 한다(SHALL). 아코디언은 기본으로 접혀 있고, 펼치면 각 리뷰를 카드로 보여준다. 카드에는 별점, 작성자와 작성일 태그, 제목, 내용, 일치율 배지가 포함된다. 표시 건수는 응답의 sources 건수와 같고 최대 5건이다.

#### Scenario: 근거가 있는 답변
- **WHEN** 응답에 sources가 3건 포함되어 있다
- **THEN** 답변 하단에 "참고 리뷰 3건" 배지가 보이고 아코디언은 접혀 있다

#### Scenario: 아코디언 펼침
- **WHEN** 사용자가 배지 또는 아코디언 헤더를 누른다
- **THEN** sources 건수만큼 카드가 펼쳐지고 각 카드에 별점, 작성자·작성일 태그, 제목, 내용, 일치율 배지가 표시된다

#### Scenario: 근거 없음
- **WHEN** 응답의 sources가 비어 있다
- **THEN** 아코디언과 배지는 표시되지 않는다

## ADDED Requirements

### Requirement: 리뷰 카드 별점 표시
시스템은 각 리뷰 카드에 별점을 노란색으로 채운 별 아이콘 최대 5개로 시각화해야 한다(SHALL). 채워지는 별의 개수는 평점을 반올림해 0~5 범위로 제한한 값이고, 나머지는 비어 있는 별로 표시한다. 별점 영역에는 평점을 알려주는 접근 가능한 이름이 있어야 한다.

#### Scenario: 4점 리뷰
- **WHEN** 평점이 4인 리뷰 카드가 표시된다
- **THEN** 노란색으로 채워진 별 4개와 비어 있는 별 1개가 보이고, 접근 가능한 이름은 "평점 4점"이다

#### Scenario: 범위를 벗어난 평점
- **WHEN** 평점이 7이거나 -1이다
- **THEN** 채워지는 별은 각각 5개, 0개이다

### Requirement: 리뷰 카드 메타 태그
시스템은 각 리뷰 카드에 작성자와 작성일을 아이콘이 있는 태그로 표시해야 한다(SHALL). 작성일이 `YYYY-MM-DD` 형식이면 `YYYY.MM.DD`로, 다른 형식이면 원문 그대로 보여준다. 값이 없는 태그는 표시하지 않는다.

#### Scenario: 작성자와 작성일
- **WHEN** 작성자가 "배터리괴물"이고 작성일이 "2024-02-01"인 카드가 표시된다
- **THEN** "배터리괴물" 태그와 "2024.02.01" 태그가 보인다

#### Scenario: 값이 없는 태그
- **WHEN** 작성자나 작성일이 비어 있다
- **THEN** 해당 태그는 표시되지 않고 나머지 태그와 카드 내용은 정상 표시된다

#### Scenario: 다른 형식의 작성일
- **WHEN** 작성일이 "2024/02/01"처럼 `YYYY-MM-DD`가 아니다
- **THEN** 작성일 태그에는 원문이 그대로 표시된다

### Requirement: 리뷰 내용 말줄임과 펼치기
시스템은 리뷰 내용을 기본으로 2줄까지만 보여주고 넘치면 말줄임 처리해야 하며(SHALL), 말줄임이 발생한 경우에만 내용 또는 "더보기" 버튼을 눌러 전체를 펼치고 "접기"로 다시 줄일 수 있어야 한다. 펼침 상태는 카드마다 독립적이고, 토글은 키보드로도 조작할 수 있으며 현재 상태를 `aria-expanded`로 알린다.

#### Scenario: 긴 내용
- **WHEN** 내용이 카드 너비에서 2줄을 넘는다
- **THEN** 2줄까지만 보이고 말줄임 처리되며 "더보기" 버튼이 표시된다

#### Scenario: 펼치기와 접기
- **WHEN** 사용자가 말줄임 처리된 내용 또는 "더보기" 버튼을 누른다
- **THEN** 전체 내용이 보이고 버튼은 "접기"로 바뀌며 `aria-expanded`가 `true`이다. 다시 누르면 2줄로 돌아간다

#### Scenario: 짧은 내용
- **WHEN** 내용이 2줄 이내이다
- **THEN** 말줄임과 토글 버튼이 표시되지 않는다

#### Scenario: 카드별 독립
- **WHEN** 한 카드의 내용을 펼친다
- **THEN** 다른 카드의 펼침 상태는 바뀌지 않는다

#### Scenario: 너비 변화
- **WHEN** 창 너비가 바뀌어 같은 내용이 2줄을 넘게 되거나 2줄 이내가 된다
- **THEN** 토글 버튼이 그에 맞게 나타나거나 사라진다

### Requirement: 일치율 배지
시스템은 각 리뷰 카드에 검색 점수를 백분율로 바꾼 "N% 일치" 배지를 표시해야 한다(SHALL). N은 점수에 100을 곱해 반올림한 값이며 0~100으로 제한한다. 점수가 숫자가 아니면 배지를 표시하지 않는다. 배지에는 이 값이 키워드 관련도와 도움이 됨 수를 조합한 표시용 점수이며 의미 유사도가 아니라는 설명을 툴팁과 접근 가능한 이름으로 제공한다.

#### Scenario: 점수 0.89
- **WHEN** 점수가 0.89인 카드가 표시된다
- **THEN** "89% 일치" 배지가 보인다

#### Scenario: 점수 반올림과 제한
- **WHEN** 점수가 0.885이거나 1.2이다
- **THEN** 배지는 각각 "89% 일치", "100% 일치"이다

#### Scenario: 점수 없음
- **WHEN** 점수가 없거나 숫자가 아니다
- **THEN** 일치율 배지는 표시되지 않는다

#### Scenario: 배지 설명
- **WHEN** 사용자가 배지에 마우스를 올리거나 스크린리더로 읽는다
- **THEN** 점수가 의미 유사도가 아닌 표시용 점수라는 설명이 제공된다
